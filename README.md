# 10MAA revision exams

Two unofficial printable revision papers, each with a separate worked marking schedule.

- [Paper 1](<paper-1/10MAA Revision Exam.pdf>) and [marking schedule](<paper-1/10MAA Revision Exam Schedule.pdf>): 160 marks, suggested time 2 hours 25 minutes.
- [Paper 2](<paper-2/10MAA Revision Exam Paper 2.pdf>) and [marking schedule](<paper-2/10MAA Revision Exam Paper 2 Schedule.pdf>): 135 marks, suggested time 2 hours. Its coverage and length were informed by the 2024 and 2025 10MAA end-of-year papers.

The official past papers are not redistributed here.

## Build

Install [uv](https://docs.astral.sh/uv/) and the Liberation Serif and Liberation Sans fonts. From the repository root:

```sh
uv run --with typst --with pymupdf python build.py
```

The build writes each paper and its schedule in its own directory, and page previews and margin checks under `review/` (not tracked by Git). The papers have separate sources, layout files, assets and standalone build scripts. Changes to one do not affect the other. To build just one paper, run its `build.py` from its directory using the same `uv run --with typst --with pymupdf python build.py` command. Each paper has a separate TikZ diagram pipeline; see its `diagrams/README.md` for regeneration and checks.

These papers and worked solutions were generated with AI. Errors may remain. Paper 1 was generated by GPT-6.1 Sol; paper 2 by GPT-6.1 Terra. The OpenAI cover symbol does not imply endorsement.
